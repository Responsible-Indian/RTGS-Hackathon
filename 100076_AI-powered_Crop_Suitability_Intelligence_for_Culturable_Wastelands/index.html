Systemic Constraints

Where the Pipeline Fractures
Intelligence Trapped Between Satellite and Soil

The problems persist not from lack of data or intent, but from systemic disconnects in how information flows—or fails to flow—from remote sensing platforms to actionable village-level plans. Here's why the intelligence never reaches the field.

B1

The Resolution Gap

Sentinel-2 imagery at 10m resolution and Planet data at 3m cannot be seamlessly fused. Add vector-based cadastral boundaries from Meebhoomi, and spatial mismatches multiply. No standardized pipeline exists to harmonize these incompatible formats into unified parcel-level analysis.

Format Incompatibility
B2

Islands of Information

APSAC soil data, irrigation availability, terrain features, and market proximity remain isolated in separate databases. Without a unified predictive matrix, these complementary datasets cannot inform holistic crop suitability decisions—each exists in its own administrative vacuum.

Systemic Fragmentation
B3

The Processing Vacuum

A five-year satellite archive plus weekly Planet imagery creates massive data volume. Without automated spatiotemporal processing pipelines, analysis depends on manual GIS work that cannot scale. Cloud masking, seasonal filtering, and temporal compositing remain labor-intensive bottlenecks.

Capacity Mismatch
B4

The Validation Void

When AI classifies a parcel as wasteland but farmers report otherwise, there's no structured mechanism to correct the system. Field survey data and farmer inputs have no pathway back into the classification model. Errors persist and compound across seasons without correction.

No Learning Loop
B5

Lost in Translation

Complex parcel-scale analytics and statistical suitability data remain incomprehensible to field workers. No intuitive visual interfaces exist to translate technical outputs into actionable crop recommendations that local agricultural officers can apply during farmer engagements.

Usability Barrier
B6

The Handoff Disappears

Even when village-wise expansion plans are created, no clear pathway exists to connect analysis with action. How does a finalized crop recommendation reach subsidy distribution channels, extension services, or on-ground execution teams? The workflow simply ends without defined handoffs.

Process Gap

The Underlying Constraint: Absence of an Integrated Intelligence Pipeline

All these bottlenecks stem from a single systemic gap: no unified, automated pipeline connects satellite observation to village-level action. Data exists at every stage—satellite archives, soil databases, cadastral records, market information—but without an integrated system to fuse, process, validate, and translate this intelligence, it remains trapped in silos. The result is a reactive, manual process that cannot scale to meet the scope of Andhra Pradesh's agricultural potential.

End-to-end user experiences across six key personas in the AI-Powered Crop Suitability Intelligence System for Culturable Wastelands.

Village Agriculture Assistant (VAA)

Field-level agricultural extension workers who visit farmer parcels, conduct ground-truth verification, and communicate recommendations. Operate on budget Android smartphones (2GB RAM) in areas with intermittent or no connectivity. Approximately 10,000 VAAs across AP.

Verify Wasteland Classification and Collect Ground Truth

Primary Flow
1

Launch mobile app and navigate to assigned mandal view

Offline map loads from SQLite cache via Room DB; Mapbox vector tiles (<2MB/village) render wasteland parcels color-coded by confidence (red <70%, yellow 70-85%, green >85%); GPS via Android Location API confirms device position

VAA Mobile App (Kotlin + Jetpack + Mapbox SDK)
2

Select parcel flagged for verification and walk to GPS coordinates

Spatial query against local SQLite PostGIS-lite extension; R-tree index enables <50ms parcel lookup; GPS accuracy threshold 20m enforced before allowing verification; offline routing via cached road network

VAA Mobile App (Room DB + GPS Location Services)
3

Capture geotagged photos of land from multiple angles

CameraX API captures JPEG with embedded EXIF (GPS, timestamp, device ID); TFLite MobileNetV2 (1.5MB, INT8 quantized) validates photo depicts actual land vs fraudulent images in <500ms on Snapdragon 400; confidence >0.85 required

On-Device Photo Validator (TFLite MobileNetV2 + CameraX)
4

Record field observations: actual land use, vegetation, soil characteristics

Structured form with dropdown validation persists to Room DB; offline-first pattern stores immediately; Telugu voice input via on-device ASR (Vakyansh model) for illiterate users; EXIF metadata auto-attached

VAA Mobile App (Room DB + Vakyansh ASR)
5

Swipe left/right to indicate agreement or disagreement with AI classification

Binary feedback stored as training signal; disagreements trigger priority review queue; gesture-based UI optimized for sunlight readability; feedback JSON queued in WorkManager for background sync

VAA Mobile App (WorkManager + Background Sync)
6

Return to connectivity zone; data syncs automatically

WorkManager detects unmetered Wi-Fi; Protocol Buffers compress payload 60-80%; chunked upload with resume; SMS fallback via NIC Gateway after 3 TCP failures; conflict resolution: server wins for classifications, client wins for observations

Edge Sync Service (Protocol Buffers + NIC SMS Gateway)
